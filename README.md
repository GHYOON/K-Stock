# K-Stock 📈

삼성전자 · 삼성전기 · SK하이닉스의 **실시간 주가와 시가총액**을 확인하고,
**삼성전자와 SK하이닉스의 시가총액 격차**를 비교해 주는 CLI 프로그램입니다.

> "하이닉스가 삼성전자에 얼마나 가까워졌나?"를 한눈에 보여줍니다.

## 대상 종목

| 종목 | 코드 | 야후 심볼 |
|------|------|-----------|
| 삼성전자 | 005930 | 005930.KS |
| 삼성전기 | 009150 | 009150.KS |
| SK하이닉스 | 000660 | 000660.KS |

## 요구 사항

- Python 3.8 이상
- 인터넷 연결 (네이버 증권 / 야후 파이낸스 접근)
- **외부 패키지 불필요** — 표준 라이브러리만 사용합니다.

## 실행 방법

```bash
# 1회 조회
python main.py

# 30초마다 자동 갱신 (Ctrl+C 로 종료)
python main.py --watch 30

# JSON 형식으로 출력 (다른 프로그램과 연동할 때)
python main.py --json
```

## 동작 방식

1. **네이버 증권 모바일 API** 를 1순위로 시도해 현재가·상장주식수를 가져옵니다.
2. 실패하면 **야후 파이낸스 차트 API** 로 폴백합니다.
3. 시가총액 = `현재가 × 상장주식수` 로 계산합니다.
   상장주식수를 실시간으로 못 가져오면 `kstock/stocks.py`의 폴백값(보통주
   기준)을 사용합니다.

> ⚠️ 시가총액은 **보통주 기준**입니다. 삼성전자 우선주(005935)는 포함하지
> 않으며, 이는 일반적으로 보도되는 "시가총액" 헤드라인 수치와 동일한
> 기준입니다.

## 프로젝트 구조

```
K-Stock/
├── main.py              # CLI 진입점
├── requirements.txt
├── README.md
└── kstock/
    ├── __init__.py
    ├── stocks.py        # 종목 정의 (코드 / 상장주식수 폴백)
    ├── fetch.py         # 데이터 조회 (네이버 → 야후 폴백)
    └── report.py        # 출력 포매팅 + 시가총액 비교 계산
```

## 참고

- 장 마감 후에는 종가 기준으로 표시됩니다.
- 상장주식수 폴백값은 가끔 변동(자사주 소각/증자 등)될 수 있으므로,
  정확한 비교가 필요하면 `kstock/stocks.py`의 값을 최신으로 갱신하세요.
